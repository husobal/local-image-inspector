# Local Image Inspector

A lightweight, single-file image inspector that runs entirely in your browser.

Browse, filter and sort local images by resolution, file size, format, aspect ratio and more.

No installation. No uploads. No dependencies.

## Download

[Download Local Image Inspector](https://github.com/husobal/local-image-inspector/releases/download/v1.0.0/image-inspector.html)

Download the HTML file, open it in your browser, and select a folder.

## Features

- Single HTML file
- Works offline
- No server required
- No image uploads
- Browse folders and subfolders
- VS Code-style folder tree
- Search by file name
- Filter by:
  - Format
  - Orientation
  - Aspect ratio
  - Width
  - Height
  - Exact dimensions
  - File size
- Sort by:
  - Resolution
  - File size
  - Width
  - Height
  - Megapixels
  - File name
  - Modified date
- Responsive interface
- Lazy thumbnail loading
- Optimized handling for high-resolution images
- Local thumbnail caching while the page remains open

## Usage

1. Download `image-inspector.html`
2. Open it in a modern web browser
3. Click **Open Folder**
4. Select a folder containing images
5. Browse, filter and sort your images

Subfolders are scanned automatically.

## Privacy

All processing happens locally in your browser.

Your images are never uploaded or sent anywhere.

## Requirements

A modern web browser such as:

- Chrome
- Edge
- Safari
- Firefox

No Python, Node.js or additional software is required.
